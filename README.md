# CryptoDCA Pro - Smart DCA & Profit Calculator

A modern, responsive, and lightweight web application designed for crypto traders and investors to calculate **Dollar-Cost Averaging (DCA)**, target exit profits, and net returns after exchange trading fees.

Live Demo ready for **GitHub Pages**.

---

# 🚀 Features

- **DCA Calculator:** Add multiple purchase entries (price & amount/quantity) to calculate exact weighted average buy price and total investment.
- **Profit & Target Exit Planner:** Calculate expected ROI (%), total payout, and net profit based on target exit prices.
- **Exchange Fee Deduction:** Built-in calculation for maker/taker spot trading fees (default 0.1% customizable).
- **Persistent Storage:** Automatically saves your calculation history locally in browser `localStorage`.
- **Responsive Dark Mode UI:** Clean, modern financial dashboard design optimized for mobile and desktop screens.
- **Zero Dependencies:** Pure vanilla HTML5, CSS3, and modern JavaScript — no frameworks or build steps required.

## 🛠️ How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/crypto-dca-pro.git
   ```
2. Navigate to the project directory:
   ```bash
   cd crypto-dca-pro
   ```
3. Open `index.html` directly in any web browser.

---

## 🌐 Deploy to GitHub Pages (Free)

1. Go to your GitHub repository settings: **Settings > Pages**.
2. Under **Source**, select `Deploy from a branch`.
3. Choose branch `main` and folder `/ (root)`, then click **Save**.
4. Your website will be live at `https://your-username.github.io/crypto-dca-pro/` in 1-2 minutes!
